image-engine.ts의 실제 마스크 계산 로직(boxBlur → smoothStep(0.42, 0.7))을 그대로 옮겨온 "현재 코드"는 피부색·질감이 다른 흉터 부위를 배경으로 오탐해 구멍을 뚫습니다. "수정판"은 테두리와 연결되지 않은 내부 구멍만 골라 피부로 승격시켜서 이 문제를 고칩니다.

기본값에는 이미 흉터 하나와 다리 사이 틈이 그려져 있습니다. 아무 곳이나 드래그하면 바로 새 흉터를 추가할 수 있고, 아래 결과들이 실시간으로 같이 바뀝니다.

신뢰도 점수 입력

밝을수록 "사람"일 확률이 높다고 AI가 준 점수. 여기에 직접 그리세요.

2마스크가 어떻게 다르게 나오는지 비교하세요

같은 입력인데 현재 코드는 흉터 자리를 구멍(검정)으로 남기고, 수정판은 그 구멍만 골라 메웁니다. 다리 사이 틈(진짜 배경)은 둘 다 그대로 유지되어야 정상입니다.

현재 코드 마스크 버그

buildPersonMask() 그대로. 흉터 위치가 검은 구멍으로 남음.

수정판 마스크 패치

테두리와 안 이어진 내부 구멍만 인물로 승격. 다리 사이 틈은 그대로 유지.

3실제 타투 합성 결과로 확인하세요

마스크 구멍이 실제로는 어떤 결과를 만드는지 보여줍니다. 현재 코드는 흉터 자리에 잉크가 없어 살색이 그대로 비어 보이고, 수정판은 정상적으로 잉크가 채워집니다.
